# JS Practice

## Description

This project is a collection of solutions and implementations for various programming challenges and common coding interview topics. The structure of the project is organized into different folders to facilitate easy navigation and categorization of the content.

## Folder Structure

The repository is organized by functional domain to help with focused learning:

### 1. **javascript/**

- Contains core JS concepts (`jsquestion/`, `promises/`, `polyfills-utils/`, `js30/`, etc.).

### 2. **dsa/** (Data Structures and Algorithms)

- Algorithms, data-structures (`linkedList`, `tree`, `graph`), sorting, and LeetCode (`lc`) solutions.

### 3. **typescript/**

- TypeScript practice, types, and compiler questions.

### 4. **html/ & css/**

- **Master Web Index (`html/web/`)**: A dedicated learning hub emphasizing pure vanilla paradigms. Features an interactive Project Wiki and dynamic data-driven cards explaining the 'why' behind semantic architecture.
  - **Lab 1 (Semantic Forms)**: Deep dive into input validation, labels, and robust form structuring.
  - **Lab 2 (A11y)**: Advanced accessibility implementing ARIA roles, focus trapping, and live regions.
  - **Lab 3 (CSS Shapes)**: An interactive engine for rendering complex `clip-path` geometry safely decoupled from JS.

### 5. **react/, nodejs/**

- Framework and server environment specific logic, lifecycle methods, and core principles.

### 6. **design-patterns/ & principles/**

- Architectural patterns (Observer, Factory, Singleton) and pure software engineering principles.

### 7. **machine-coding/**

- System UI problems and full JS/React specific UI implementation challenges (e.g., Progress Bars, Whack-a-Mole).

### 8. **testing/**

- Information and setups related to writing robust test cases.

## Usage

Feel free to explore the folders based on your interests or specific learning goals. Each folder contains its own set of challenges and solutions. You can use the code for reference, learning, or even contribute by adding your own solutions.

localStorage as a cache: trade-offs
  • Size: roughly 5 MB per origin, strings only, so data must be serialised and old entries pruned.
  • Sync: reads and writes block the main thread; large JSON parses can cause jank.
  • Staleness: data can be out of date, so entries carry a timestamp and expire after a TTL.
  • Sharing: other tabs see the same data but are not notified unless they listen for the storage event.
  • Availability: storage can be disabled or full, so every access is wrapped in try/catch and the in-memory Map still works.

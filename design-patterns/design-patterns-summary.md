---

## Pattern quick notes

- `abstract-factory.js`: family of related factories.
- `factory.js`: create objects through a dedicated creator.
- `builder.js`: build objects with method chaining.
- `decorator.js`: wrap and extend behavior.
- `facade.js`: one interface for many subsystems.
- `iterator.js`: traverse collections consistently.
- `observer.js`: notify listeners on update.
- `prototype.js`: clone from an existing object.
- `proxy.js`: intercept and control object access.
- `singleton.js`: preserve one shared instance.
